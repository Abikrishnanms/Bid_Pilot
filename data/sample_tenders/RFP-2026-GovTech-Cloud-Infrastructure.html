REQUEST FOR PROPOSAL (RFP)

Reference: RFP-2026-CLOUD-09 | Issuing Authority: GovTech Public Digital Services

Project Title Enterprise Cloud Infrastructure Modernization & AI Analytics Platform
Issuing Organization GovTech Agency (Public Sector)
Estimated Contract Budget $5,000,000 USD
Submission Deadline November 30, 2026 - 17:00 UTC
Project Location Washington D.C. / Remote Support

1. Scope & Objective

GovTech Agency invites qualified enterprise software and cloud engineering vendors to bid for the architectural overhaul of its legacy data systems. The selected contractor will design, containerize, and deploy a secure microservices data platform featuring AI-assisted semantic search and vector retrieval.

2. Eligibility & Organizational Requirements

  • The bidding vendor must possess a minimum of 10+ years of documented corporate experience in enterprise cloud infrastructure, DevOps, and multi-tenant architectures.
  • Vendor must maintain an active technical delivery team of at least 25 full-time engineers specializing in Python, PostgreSQL, and distributed systems.
  • Vendor must demonstrate positive operating cash flow and audited financial statements for the past 3 fiscal years.

3. Technical Requirements

  • Modern microservices backend engineered using Python (FastAPI) and asynchronous concurrency.
  • Relational database storage with vector embedding indexing powered by PostgreSQL with pgvector extension.
  • Implementation of Retrieval-Augmented Generation (RAG) to query across millions of unstructured records.
  • Production deployment utilizing Docker containerization and Kubernetes orchestration.

4. Compliance & Mandatory Certifications

  • Mandatory ISO 9001 Quality Management System certification.
  • Mandatory ISO 27001 Information Security Management certification (Non-negotiable).
  • Full compliance with SOC2 Type II operational security controls.

5. Deliverables & Evaluation Criteria

  • Deliverable 1: Cloud Architecture Blueprint and Migration Strategy Document.
  • Deliverable 2: Production-grade containerized microservices codebase with comprehensive automated test suite.
  • Evaluation split: Technical Competence (60%), Past Performance & Evidence (25%), Cost Proposal (15%).
